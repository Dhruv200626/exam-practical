Introduction to Servlet Create and deploy a basic HTTP Servlet
Done ▼

Aim

To write a simple Java Servlet that handles an HTTP GET request and sends an HTML response to the browser.

Code

HelloServlet.java 
import java.io.*;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import jakarta.servlet.annotation.*;

@WebServlet("/hello")
public class HelloServlet extends HttpServlet {

    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {

        res.setContentType("text/html");
        PrintWriter out = res.getWriter();

        out.println("<html><body>");
        out.println("<h2>Hello from Servlet!</h2>");
        out.println("<p>Your first servlet is running.</p>");
        out.println("</body></html>");
    }
}

Output

Browser displays: Hello from Servlet! — Your first servlet is running.

Servlet with Form Handling (POST) Read HTML form data using HttpServletRequest

Aim

To create an HTML form that submits data to a Servlet via POST method and display the received data.

HTML Form (index.html)

form.html 
<form action="formServlet" method="post">
  Name: <input type="text" name="name" />
  Age:  <input type="text" name="age"  />
  <input type="submit" value="Submit" />
</form>

Servlet (FormServlet.java)

FormServlet.java 
@WebServlet("/formServlet")
public class FormServlet extends HttpServlet {

    protected void doPost(HttpServletRequest req,
                          HttpServletResponse res)
                          throws IOException {

        String name = req.getParameter("name");
        String age  = req.getParameter("age");

        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        out.println("<h2>Hello, " + name + "!</h2>");
        out.println("<p>Age: " + age + "</p>");
    }
}

Output

After submitting the form: Hello, [Name]! Age: [Age]

JDBC – Database Connection Connect to MySQL and fetch records
Done ▼

Aim

To establish a JDBC connection with a MySQL database and retrieve data from a table.

Code

JDBCDemo.java 
import java.sql.*;

public class JDBCDemo {
    public static void main(String[] args) {
        String url  = "jdbc:mysql://localhost:3306/mydb";
        String user = "root";
        String pass = "password";

        try (Connection con = DriverManager.getConnection(url, user, pass)) {
            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery("SELECT * FROM students");

            while (rs.next()) {
                System.out.println(
                    rs.getInt("id") + " | " +
                    rs.getString("name")  + " | " +
                    rs.getInt("age")
                );
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}

Output

Console prints: 1 | Alice | 20, 2 | Bob | 21, etc.

Session Management Using HttpSession to maintain user state
Pending ▼

Aim

To demonstrate session management in Java Servlets using HttpSession to store and retrieve user data across requests.

Code

SessionServlet.java 
@WebServlet("/session")
public class SessionServlet extends HttpServlet {

    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {

        // Create or get existing session
        HttpSession session = req.getSession(true);
        session.setAttribute("username", "Alice");
        session.setAttribute("visits",
            (Integer) session.getAttribute("visits") == null
            ? 1
            : (Integer) session.getAttribute("visits") + 1);

        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        out.println("User: "    + session.getAttribute("username"));
        out.println("Visits: "  + session.getAttribute("visits"));
        out.println("Session ID: " + session.getId());
    }
}

Output

Browser shows the username, visit count, and session ID. Visit count increments on each reload.

Hibernate – ORM Basics Map a Java class to a database table using Hibernate
Pending ▼

Aim

To use Hibernate ORM to save and retrieve a Java entity object from a MySQL database table without writing SQL manually.

Entity Class

Student.java 
import jakarta.persistence.*;

@Entity
@Table(name = "students")
public class Student {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private int id;

    @Column(name = "name")
    private String name;

    // Getters and Setters
    public int    getId()   { return id; }
    public String getName() { return name; }
    public void   setName(String n) { this.name = n; }
}

Main Class

HibernateDemo.java 
import org.hibernate.*;
import org.hibernate.cfg.*;

public class HibernateDemo {
    public static void main(String[] args) {
        SessionFactory factory = new Configuration()
            .configure("hibernate.cfg.xml")
            .addAnnotatedClass(Student.class)
            .buildSessionFactory();

        Session session = factory.getCurrentSession();
        try {
            Student s = new Student();
            s.setName("Alice");

            session.beginTransaction();
            session.save(s);
            session.getTransaction().commit();

            System.out.println("Saved student: " + s.getId());
        } finally {
            factory.close();
        }
    }
}

Output

Console: Saved student: 1 — and a row is inserted in the MySQL students table.
